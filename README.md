# 塗裝編輯器 使用說明

雙擊 `塗裝編輯器.html` 就能用（建議用 Edge 或 Chrome 開啟），不用安裝任何東西。

## 使用流程（全自動）

1. 按 **開啟圖片** → 選車輛的 DDS 檔（例如 `70camryk_sign_1.dds`）
2. 在右邊輸入要改的內容（留空的欄位不會動）：
   - **地區**：例如 `臺中市政府警察局`
   - **分局**：例如 `第五分局`
   - **編號**：例如 `568`
   - **車頂簡稱**：通常留空讓它自動產生（臺北市政府警察局→北市、中正第一分局→中正一），要不同的寫法再自己填
3. 按 **自動偵測並套用**
4. 檢查畫面（橘框是自動改好的地方），沒問題按 **匯出 DDS**
5. 檔案會下載到「下載」資料夾 → 用 OpenIV 匯回遊戲的 ytd

## 自動偵測會幫你處理的事

- 自動找到圖上**所有**該類文字的位置（不管幾個）
- 字體大小自動配對成跟原本一樣大
- 文字顏色、背景顏色自動取樣原圖
- 車身右側「由右到左」的反序寫法（局分三第）自動判斷並產生對應反序新字（數字不反序）
- 數字間距自動調成跟原本一樣寬
- 原文字若有傾斜，會自動量出角度讓新字一樣斜
- 車頂的「編號＋分局簡稱＋地區簡稱」直排組合會自動認出，整組倒轉 180 度的也會照原方向寫
- 舊字用不同字型（黑體、明體、鏤空方塊數字）也認得出來
- 只塗掉舊字的筆畫，旁邊的車身色塊、警徽等圖案不會被動到
- 沒有字的空白貼圖、參考圖上的雜紋不會被誤判成文字

## 字型設定

- **數字字型／中文字型**：各自可選字型和粗細（一般／半粗／粗／特粗），換了之後已套用的字會自動重新排版，字高仍對齊原本的字
- 預設：數字＝Arial Black 特粗、中文＝標楷體一般
- 像「901」那種一般粗細的數字：選 **Arial Bold** 或 **Segoe UI ＋ 半粗**（選 Arial Bold 時粗細會自動切到「粗」）
- **數字字距**：勾「自動」＝照原圖的字距；取消勾選後用滑桿或輸入框自己調（單位是字高的百分比，0＝字型本身的間距，負數＝更緊，最寬 100%）。拉動時馬上看到效果
- 只想改某一處編號的字距：打開「手動微調」，點那個框，改「字距」（像素）
- 選單最下面的「**載入字型檔…**」可以載入自己的 .ttf / .otf 字型，載入一次之後會記住，下次打開還在
- 每個檔案會記住當時用的字型

## 傾斜角度

- 「傾斜角度」欄位填 0 ＝自動沿用原文字量到的角度
- 想自己指定就填度數：**正值＝右邊高（前低後高）**，反序面會自動用相反方向
- 個別文字框也可以在「手動微調」裡單獨調傾斜

## 如果自動結果有小偏差

打開下方「手動微調」：
- 點畫面上的框選取 → 改文字、大小、顏色、鏡像
- 拖曳框＝移動；拖右下角綠點＝調大小；方向鍵微調；Delete 刪除
- 「＋手動新增文字框」可以在任何地方加字（拖曳畫框）
- 「吸管」按下後點圖片取色

## 改其他車輛

任何車的塗裝 DDS / PNG 都能直接開，操作完全相同。
每個檔案的欄位內容和文字框會**依檔名自動記住**，下次打開會還原。
「儲存範本 / 載入範本」可以把設定存成 json 備份或搬到別台電腦。

## 匯出格式

- **匯出 DDS**：跟原檔格式一致——原檔有 mipmap 就產生同樣層數的 mipmap；原檔有用到透明度就輸出 DXT5，否則 DXT1。可直接匯回 OpenIV
- **匯出 PNG**：一般圖片，方便檢查

## tools 資料夾（輔助小工具，平常用不到）

- `dds2png.js`：命令列把 DDS 轉 PNG：`node dds2png.js 輸入.dds 輸出.png`
- `test_roundtrip.js`：測試 DDS 編碼品質用
